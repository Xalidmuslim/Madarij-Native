# Восстановление из истории команд

Локальные переводы после восстановления среды отсутствовали. Здесь сохраняются точные исходные payload из истории выполненных команд. Промежуточные JSON могут покрывать только часть указанного в имени диапазона. Это не новый перевод и не восстановление прежних Git-коммитов. Канонические файлы тома будут обновлены после полного восстановления и проверки. Файлы с completed:true дополнительно проверяются перед объединением.
