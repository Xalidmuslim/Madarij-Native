# Второй том — партия перевода 11–80 (70 страниц)

Дата редакции: 11 октября 2026 года.

## Состав
- Исходный арабский текст: печатные страницы 11–80 выбранного издания 2019 года; берётся из независимого файла `research/volume2-source/arabic_pages.jsonl`.
- Русский текст: семь файлов по десять страниц в данном каталоге.
- Связь текста с источником: один стабильный идентификатор на страницу; перекрёстные переходы русских предложений между страницами сглаживаются при импорте.
- Текст приложения: `app/src/main/assets/volume2-preview.json`, отдельно от первого тома.

## Статус
**Это предварительный рабочий перевод, не окончательное научно-богословское издание.** Полнота 70 печатных страниц проверена технически; независимая сверка смысла всех 70 страниц по сканам, редакторские сноски современного издателя и хадисоведческая экспертиза не завершены.

Проверить при подготовке к выпуску:
- корректность смысловых переходов между печатными страницами и заголовков разделов;
- цитирование аятов и номера сур;
- страницу 46: фраза «Кто познал себя, тот познал своего Господа» — **не хадис**;
- страницы 44 и 51: в перечислении взглядов встречаются отличающиеся порядковые номера;
- страницы 53–54 и 63: оценка хадисов требует `тахриджа` и сверки по первоисточникам;
- страницу 78: история об обращении к Аллаху 40 раз — слова, приписываемые Ибн Таймийе, а не утверждённая пророческая Сунна.

Первый том, закладки, заметки, цветовая схема и навигация прежней версии сохранены. Автоматический машинный перевод Open-source моделей сознательно не использован для этого пакета из-за обнаруженных смысловых искажений.
