## Порядок работы

Редакторский цикл: **по 5 навигационных разделов**, а не по 5 авторских глав. Всего в первом томе 90 навигационных разделов, то есть 18 партий. Границы блоков могут проходить посередине авторского предложения; при корректуре проверять смежные абзацы.

### Обязательные правила

- Сохранять смысл арабского оригинала, доказательную последовательность, повторы с риторической функцией, метафоры и богословские противопоставления.
- Аяты и хадисы **не переписывать ради художественного стиля**. Их перевод и атрибуция требуют отдельного протокола проверки.
- Не менять `chapterId`, `paragraphId`, `order`, навигационные границы, заметки, закладки и историю чтения.
- Внести точечную правку по её оригинальному выражению в `batch01_pages003_034.json`, с кратким объяснением. Отсутствие точного совпадения при сборке — ошибка, а не основание подставить текст молча.
- Полные арабские оригиналы **не удалять из исследовательской базы**; они необходимы, чтобы различать литературную правку от смыслового искажения. В APK упаковывается только русский текст без арабской графики.
- Статус: это литературная редакция рабочего перевода. Независимая религиоведческая, богословская и хадисоведческая экспертиза **не завершена**.

### Исследовательский двуязычный корпус (не основной формат сравнения)

Каждая партия фиксируется в `batchNN_pages*.json`. Отдельный сценарий `tools/build_reviewed_bilingual.py` последовательно применяет точные правки к **полной двуязычной копии** первого тома. `tools/render_reviewed_bilingual.py` создаёт автономную HTML-версию с арабским оригиналом и русским переводом рядом и выделением исправленных текстовых блоков.

```bash
python3 -m unittest -v tools.test_reviewed_bilingual
python3 tools/build_reviewed_bilingual.py
python3 -m tools.render_reviewed_bilingual
```

В ветках `editorial/**` GitHub Actions `editorial-bilingual-corpus.yml` собирает только текстовый архив (полный JSON + HTML), **без Android, Gradle и APK**. Артефакты Actions доступны 90 дней, а исходный корпус, редакторские манифесты и генераторы сохраняются в GitHub постоянно и позволяют получить заново тот же результат.

В финальной сборке приложение получит все проверенные партии через `tools/prepare_russian_reader_assets.py`, который сформирует русскоязычный набор ресурсов, не включая арабские тексты в APK. Пока финальная сборка не требуется.

### Сравнение русских текстов: «было / стало»

Начиная с четвёртой партии пользовательский архив содержит **два русских текста рядом**, а не арабский оригинал и русский перевод. `tools/render_russian_changes.py` формирует:

- `russian-before-after.html` — автономный сравнительный документ; выводятся только изменённые абзацы, прежний русский слева, исправленный справа, изменённые места выделены;
- `russian-before-after.json` — машинно-читаемое сравнение тех же абзацев, с причинами исправлений и IDs.

Все сохранённые партии входят в этот экспорт; новейшая располагается первой. Арабский оригинал остаётся в защищённом исследовательском корпусе для смысловой проверки, **но не входит в эти пользовательские сравнительные файлы как отдельный текст**. Необходимо запускать `python3 -m unittest -v tools.test_reviewed_bilingual tools.test_russian_comparison tools.test_russian_reader_assets` перед любым итоговым экспортом.
