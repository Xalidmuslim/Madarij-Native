# Степени идущих — нативное приложение для Android

Независимый проект книги «Степени идущих» Ибн аль-Каййима.

Исходная рабочая версия находится в репозитории `Xalidmuslim/AlFatiha-Native`, в ветке `madarij-v116-premium-20261007` (commit `63eb7b0a4f7f36d0736d73d03c4a1f09ac1e5831`).

## Миграция

Исходники предстоит восстановить из проверенных архивов исходной ветки, **с сохранением существующих текстов, логики и дизайна**. Упакованные данные не должны заменяться новой реализацией или сгенерированным содержимым.

Рабочая ветка «Компаса сердца» и старые ветки остаются нетронутыми.

## Сборка

После безопасного импорта будет использоваться GitHub Actions, публикующий проверяемый APK в разделе Artifacts. До завершения импорта отсутствие исходников в этом репозитории не означает, что они потеряны.
