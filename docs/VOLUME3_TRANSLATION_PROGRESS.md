1. Прочитать этот журнал и редакторские замечания; проверить ветку, `git status`, удалённый SHA и фактические файлы.
2. Запустить `python3 tools/validate_volume3.py`. Его положительный результат для частичного черновика не означает полноту тома.
3. Получить читаемый PDF выбранного издания локально (в окружении прямое скачивание вернуло HTTP 403; извлечение Firecrawl доступно, но содержит грубые искажения). 4. Продолжить незавершённый блок с указанной выше страницы; сохранять каждый подготовленный фрагмент сразу.
5. После полной готовности блока отправить его отдельным коммитом и проверить удалённый SHA. Не менять интерфейс или первые два тома ради черновой интеграции.
