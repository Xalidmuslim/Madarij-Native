# Автоматическая перепроверка тома IV — инструкция

Ветку с оригиналом и черновиком можно изучить: codex/madarij-four-volumes-20261110. По progress.json черновик 554/554 страниц готов, а 17 нерешённых редакторских вопросов ожидают дальнейшей проверки. Никаких повторных переводов уже заполненных страниц.

## Как работает

Каждые 30 минут GitHub Actions по UTC cron 17,47 проверяет очередь. Не больше одного редакторского вопроса в запуск. Один агент сравнивает арабский текст с русским черновиком, второй независимо проверяет предложения. Результат NEEDS_HUMAN_REVIEW сохраняется в отдельной ветке automation/madarij-v4-review-state как файл reviews/volume4/V4-*.json с SHA256 исходного содержания. Следующий запуск пропускает сохранённые вопросы; при изменении входа или отсутствии русского текста процесс останавливается.

Источники читаются из конкретного коммита 943f2449774a6f780707efe5ac013b042ea92619, а не из изменяемого приложения. Оригинал Корана, хадисы, переводы, вёрстка и main НЕ изменяются. Перенос предложений в книгу требует самостоятельного ревью.

## Подключение через Android

1. Проверить и вручную объединить PR с кодом и тестами в main. Пока PR не объединён, расписание не действует.
2. В Madarij-Native → Settings → Secrets and variables → Actions → Secrets добавить OPENAI_API_KEY. Ключ нельзя размещать в чате или коде.
3. В Variables добавить OPENAI_MODEL (например gpt-5-mini) и MADARIJ_AUTOREVIEW_ENABLED=true после настройки денежных лимитов API.
4. Открыть Actions → Madarij Volume 4 half-hour editorial review → Run workflow.
5. Читать отчёты в ветке automation/madarij-v4-review-state → reviews/volume4.

## Ограничения

GitHub Actions не гарантирует точную минуту запуска. До 2 платных запросов API за запуск (не более 1900 выходных токенов на запрос); это не финансовый лимит. Ошибка до записи коммита может привести к повторным тратам. ChatGPT Plus не покрывает API. Репозиторий публичный, поэтому рецензии будут публичны. PDF и печатная колляция во время запуска не проверяются: машинный результат не является научной аттестацией. Бессрочная работа не обещается: процесс закончит очередь после 17 отчётов и не будет менять материалы без одобрения.
