# Продолжение редакторской очереди без API и без ИИ-модели

GitHub Actions каждые 30 минут запускает Python-скрипт. На одном запуске он готовит один структурный пакет для следующего нерешённого вопроса тома IV из уже существующей очереди из 17 вопросов.

Проверяется существование арабского исходного фрагмента и русского черновика, соответствие ID, размер и SHA256. Новые переводы и литературные оценки НЕ создаются. Статус каждого пакета STRUCTURAL_CHECK_ONLY, а не AI_VERIFIED.

После каждого запуска пакеты фиксируются исключительно в ветке automation/madarij-v4-review-state в каталоге reviews/volume4/offline-packets/. После перезапуска ранее сохранённые вопросы пропускаются; при изменении исходника скрипт завершится ошибкой. Не затрагивает main, APK, аяты, хадисы или текст книги.

После проверки и слияния PR в main автоматические запуски запланированы в 17-ю и 47-ю минуты каждого часа UTC. GitHub может задерживать или пропускать плановые запуска. Для немедленного выполнения: Actions → Madarij Volume 4 offline continuation (no AI keys) → Run workflow.

Не нужны OPENAI_API_KEY, Copilot, подписка, VPS или настройка переменных. GitHub использует стандартный GITHUB_TOKEN для записи только в отдельную ветку. Публичный репозиторий делает результаты публичными.

Важно: это автоматическая очередь и механический контроль данных, но не автоматический перевод и не независимая научная редакция. Настоящие AI-автоматизации Copilot требуют подходящего платного плана и приватного либо внутреннего репозитория.
